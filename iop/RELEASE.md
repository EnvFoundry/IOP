# IOP 0.17.2

The research environment declaration includes repository-relative guide locations,
so hosts can describe its resources before installing a connector. IOP Connect
1.11.2 and Runtime 0.17.2 carry the same declaration. Laboratory connections,
accepted experiments, instrument configuration and scientific execution are unchanged.

环境声明新增仓库中的资料位置，宿主可在安装前展示仪器操作指南。
IOP Connect 1.11.2 与 Runtime 0.17.2 使用同一声明。
实验室连接、已接收实验、仪器配置与执行机制保持原样。
